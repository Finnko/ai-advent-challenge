# Как работает FBS

При схеме FBS продавец хранит товар у себя и собирает отправление после заказа. Срок сборки
указан в карточке отправления; если он истёк, отправление получает статус просроченного.

Чтобы исправить ситуацию, проверьте остатки, соберите отправление и передайте его в доставку.
